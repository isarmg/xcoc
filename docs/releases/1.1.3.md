# xcoc 1.1.3 候选

当前源码候选尚未发布；本页不代表已存在正式资产或已经完成平台验收。

## 本次变更

- 精确消费官方 xcsc 1.0.5；已有业务命令统一 --format human|json|ndjson，成功、失败与实际提交阶段都有结果。
- 受保护 stdin 使用公共有界读取与截止时间；交互授权码隐藏输入。
- iOS 等待摄像头授权的启动请求可取消，旧授权、连接和编码失败回调不能改变新的采集会话；未确认关闭保留句柄并阻止重新启动、配对，支持明确重试。
- iOS 原生结果校验 ABI、状态、指针和长度，C 声明由精确固定的公共 Rust ABI 生成核验。
- 同步桌面安装器、Android / iOS 和原生打包软件版本。

公共客户端源固定为 `c0cf985f82663199e270112a72bbf54ce48ff415`。软件补丁号独立于业务协议、持久状态与 FFI ABI。

- Linux 通过真实 pkg-config 传递 OpenSSL 的静态压缩依赖，并保存对应库与许可说明，避免缺失 zlib / zstd 引用。
- iOS 权限、帧、失败与停止状态按会话归属处理；关闭未确认时保留原句柄并禁止替换，允许重试停止。

## 验证边界

全功能 88 项 Rust 测试与严格 Clippy 通过，3 项依赖外部媒体工具的回归待媒体 CI；正式 FFmpeg 9.0.2 静态构建和运行库检查已在隔离目录执行。11 项原生打包检查、4 项客户端生命周期源调用检查通过。最终原生平台 CI 仍需按候选源码完成；Linux 主机验证不替代 Windows、macOS 或手机实机验收。正式包与最终交付 SHA256 校验以该版本后续发布记录为准。
